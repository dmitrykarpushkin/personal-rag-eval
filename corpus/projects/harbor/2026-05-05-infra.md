# Infra notes, Harbor

Wrote this up for Tomasz, who asked where the thing will live and who can touch it.

## Layout
- Production runs on a Hetzner dedicated box in Falkenstein; staging on a small Hetzner Cloud VM.
- Both run Docker Compose: FastAPI app, SvelteKit node server behind it, Postgres, a small worker for the nightly import, Caddy in front for TLS.
- Backups: nightly Postgres dump to object storage, kept 30 days. Restore tested once on staging (took about 12 minutes for the current data).
- Access: SSH keys for me and for Kestrel's ops person only. No password logins.

## Why this and not a big cloud
Tomasz does not want lock-in and Kestrel's volume is small. One decent box is plenty for a few hundred dispatchers' worth of reads. If it ever outgrows the box we can move the database first.

## Open items
- Uptime monitoring: pick something simple, external.
- Log shipping: for now journald plus a weekly look.
- Secrets: currently in an env file on the box, owned by root. Fine for now, flag it again at the architecture review.
- Ask Priya who on the Kestrel side gets read-only access to staging.
