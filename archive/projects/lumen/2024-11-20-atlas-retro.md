# Atlas retrospective

Project took 16 weeks, planned 14.

Went well: streaming parser decision early; pairing with support on docs; beta with two real customers.
Went badly: docs left to the end; scope creep on undo; I took on too much silently around week ten.
Learned: customers will upload anything, so design for the wrong file first.

Karl's comment: 'The best features are the error messages.' I wrote it on a sticky note.
