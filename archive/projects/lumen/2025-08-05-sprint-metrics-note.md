# Notes on sprint metrics

Kertu asked if we can measure team health without surveys. I wrote down what we already have: PR review time, number of reopened tickets, incidents per quarter, percentage of tickets carried over.

PR review time median is 6 hours, carried over is about 15%, incidents are down. None of these tell you whether people are happy. Suggested we keep the retro and add a one-question pulse.
