# Autumn, no plan

Three runs a week, 6-10 km, none with a watch face I care about. It is dark by 18:15 now so I run after work with the headlamp, in the forested path near Pelgulinn and sometimes in Kadriorg where it is lit.

Weekly mileage: around 24 km. Legs fresh, head calm.

The shoes have 450 km on them. Fine until January, then replace. Added a note to buy the same model again, plus a second pair for winter with a bit more grip.
